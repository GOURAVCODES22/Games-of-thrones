# WESTEROS — Cinematic Journey

Unofficial fan-made interactive experience. Built as a lightweight HTML/CSS/JS site with GSAP ScrollTrigger.

## Features
- Scroll-scrubbed hero video
- Cinematic chapter progression
- Great Houses explorer
- Interactive stylized Westeros map
- Character explorer with filters and modal details
- Battle chapter + parallax stage
- Dragon cinematic chapter
- Chronicle timeline
- Spoiler/death ledger
- Iron Throne finale
- Sound toggle
- Progress indicator + chapter label
- Mobile-first responsive layout
- Reduced-motion support
- SEO metadata + JSON-LD creator identity
- Instagram credit link

## Before production
