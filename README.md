# Game of Thrones — Cinematic Westeros

Unofficial fan-made cinematic website concept. Scroll controls the story: the main video is scrubbed by ScrollTrigger so moving down advances the scene and moving up reverses it.

## Features
- Scroll-scrubbed 29.7s cinematic video
- Reversible forward/backward story playback
- Chapter-aware story copy and progress bar
- Great Houses explorer with detail drawer
- Westeros interactive map hotspots
- Character explorer and filters
- Battle cards
- Dragon visual chapter
- Chronicle timeline
- Iron Throne finale
- Mobile + desktop layouts
- Reduced-motion fallback
- SEO metadata, Open Graph, JSON-LD
- Google Analytics placeholder
- Creator credit linking to CodeToCreation

## Deployment
